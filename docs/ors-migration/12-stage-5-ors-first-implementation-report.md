## 一、已实际完成

### 服务端代码

- `Settings` 新增 `ors_remote` 所需的远程 POI、驾车 profile、600/1200/1800 秒等时圈、6 km 网格、45 km² 单元面积、单元限量、请求预算、并发、超时、缓存目录、TTL 和 stale-if-error 配置。
- `OrsAdapter` 保留现有 ORS Isochrones V2 请求映射，并新增等时圈精确请求缓存；缓存键只由规范化端点和请求 JSON 组成，不含认证信息。
- 新增 `OrsRemotePoiProvider` 和 `OrsPoiClient`。远程 POI 分支不打开 `LocalPoiRepository`；`includePois=false` 时不创建 POI 请求。
- 新增 WGS84 与本地 UTM 的米制投影、等时圈外轮廓网格化、相交裁剪、单元面积计算、超面积递归拆分和 WGS84 请求几何转换。
- 新增 OpenPOIService GeoJSON 解析：稳定 OSM 身份去重、名称优先级、无名称/无稳定身份安全排除、类别分组与类别目录、未知类别诊断、原始外圈 `covers` 复核和 ring 归属。
- 新增请求预算与上游单元限量处理：计划超过预算时请求前失败；响应达到单元上限时最多递归拆分两层；仍无法完整展开时返回统一错误，不返回部分成功结果。
- 新增安全错误码，包括远程参数不接受、POI 响应无效、请求预算超限、上游截断等；错误详情不携带认证信息和完整上游响应。
- `AnalysisMetadata`、`AnalysisSources` 和前端契约已支持 `ors-public-api`、`ors-openpoiservice`、POI 覆盖统计、缓存命中、限流元数据和归因信息。
- 保留 mock 与本地 Overture 兼容路径；`local` 作为兼容输入归一化为 `overture_local`。

### 配置与前端

- `server/.env.example` 增加第五阶段远程 POI、缓存和预算配置示例；真实凭据仍只允许放在服务端本地环境中。
- 前端不再把远程 POI 误报为 Overture；数据集选择为空时可以由服务端分析模式决定使用远程 POI。
- 浏览器本地 mock 回归确认默认界面仍可生成 10/20/30 分钟结果，页面未出现 warning/error。当前源码实际中心显示为“北京·望京中心区 / 望京广场”，不是武汉。
